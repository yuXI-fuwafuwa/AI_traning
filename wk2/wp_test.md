# CF 1992E - Novice's Mistake

## 主要思路

设 `d` 为 `n` 的十进制位数。重复 `a` 次得到的字符串长度为 `a*d`，删除 `b` 个字符后剩余长度为 `a*d-b`。

剩余字符串必须非空，并且转成整数后等于 `a*n-b`。因为 `a*n-b <= a*n`，剩余字符串的长度不能超过 `to_string(a*n).size()`。因此，对每个 `a` 只需枚举

`max(1, a*d - digits(a*n)) <= b <= min(10000, a*n, a*d-1)`。

逐项构造字符串、删除后缀并比较即可。上界使用 `a*d-1`，保证删除后仍然是非空字符串。

## 详细推导

原程序的枚举上界写成了 `min(..., s.size())`。当 `b == s.size()` 时，`s.substr(0, 0)` 是空串；C/C++ 的 `atoi("")` 返回 0。对于 `n=1`，此时 `a*n-b=a-a=0`，于是 `(a,a)` 被错误加入答案，但题目明确要求程序输出非空字符串。

例如 `n=1,a=2,b=2`：原字符串为 `"11"`，删除 2 个字符后为空串，不合法；原程序却判断 `atoi("")==0==2-2`。

修正为 `s.size()-1` 后，`n=1` 的合法解正好是 `(a,a-1)`，其中 `2 <= a <= 10000`，共 9999 组。

复杂度：每个 `n` 枚举 10000 个 `a`，每个 `a` 只检查至多 7 个 `b`，总复杂度为 `O(10000 * digits(a*n))`，内存复杂度为 `O(10000 * digits(n))`（保存答案时）。
